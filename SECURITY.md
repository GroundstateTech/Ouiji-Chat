# Security

Ouiji InHouse v3.1 Alpha is an internal-network demonstration build.

The included demo accounts use the password `password`, and this alpha uses local JSON files for credentials and messages. Do not expose this build directly to the public internet or use it for sensitive production communications.

Before production deployment, use password hashing, TLS/WSS, server-side authorization, expiring/revocable sessions, rate limiting, audit logging, secure secrets management, and database-backed storage.
